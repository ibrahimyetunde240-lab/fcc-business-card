# FCC Business Card

A personalised business card webpage built with HTML and CSS as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project is a personalised digital business card designed to showcase my identity as an aspiring software developer. It includes my name, professional designation, contact information, portfolio link, and social media profiles.

## Features

- Personalised profile image.
- Name, professional designation, and company description.
- Contact information (email and phone number).
- Portfolio link.
- Social media links to Twitter, LinkedIn, and GitHub.
- Responsive image styling.

## Technologies Used

- HTML5
- CSS3

## What I Learned

- Structuring a webpage using HTML.
- Using classes to target specific elements with CSS.
- Styling and positioning elements using CSS.
- Working with background colours, margins, and padding.
- Styling links and images.
